# ALCON2026 動作指示書
提出者:Kimura Tomoaki

ID:alcon2026_017

## 1. 提出物の構成

提出用フォルダには、次の構成でファイルを配置する。

```text
alcon2026_017_実行フォルダ/
├─ alcon_017.exe
├─ _internal/
├─ weights/
│  └─ student_distilled.pt
├─ input.csv
└─ 000/ 111/ 222/ 333/
```

`alcon2026_017.exe`、`_internal`、`weights`は同じ階層に置く。画像フォルダは、`input.csv`に記載した相対パスと一致させる。

## 2. 入力ファイル

実行前に、対象画像の一覧を`input.csv`として実行フォルダに配置する。

1行目に画像枚数を記載し、2行目以降に次の形式で記載する。

```text
画像の幅,画像の高さ,画像フォルダ\画像ファイル名
```

例：

```text
10,,
5184,3888,000\P1060881.JPG
1920,1080,000\RIMG2746.JPG
```

画像ファイル名とフォルダ名は、実際の配置と完全に一致させる。

## 3. 実行方法

### コマンド実行

PowerShellを起動し、提出フォルダへ移動して実行する。

```powershell
cd C:\path\to\alcon2026_017_実行フォルダ
.\alcon2026_017.exe
```

### ダブルクリック実行

提出フォルダ内の`alcon2026_017.exe`をダブルクリックする。`input.csv`が同じフォルダにあれば実行できる。

## 4. 出力ファイル

実行後、次のファイルが作成される。

```text
output.csv
000\P1060881-output.JPG
000\RIMG2746-output.JPG
...
```

`output.csv`には、画像サイズ、出力マスク名、4段階レベル、水稲画素数、雑草画素数、その他画素数、雑草率を記録する。

## 5. 4段階判定

雑草率の閾値は、すべての画像で共通とする。

| レベル | 雑草率 |
|---:|---:|
| 0 | 3.5%未満 |
| 1 | 3.5%以上7.0%未満 |
| 2 | 7.0%以上25%未満 |
| 3 | 25%以上 |

雑草率は、次の式で計算する。

```text
雑草率 = 雑草画素数 / (水稲画素数 + 雑草画素数) × 100
```

## 6. 実行時の注意

- `input.csv`は`alcon2026_017.exe`と同じフォルダに置く。
- `weights/student_distilled.pt`を移動または改名しない。
- `_internal`フォルダを削除しない。
- `input.csv`の画像パスは、実際のファイル配置と一致させる。
- 実行中はPowerShellを閉じない。
- 同名の出力ファイルがある場合は上書きされる。

## 7. 実行確認環境

CPU: Intel(R) Core(TM) i9-10900KF @ 3.70GHz、メモリ: 32GB、OS: Windows 11で実行確認を行った。
